# Product Constitution

Status: **Implemented**

1. Determinism over opaque decision-making.
2. Explainability from output to source evidence.
3. Tenant isolation at application and database boundaries.
4. Published snapshots are immutable.
5. Every rebuild is explicit and version-aware.
6. Each bounded context owns its data and behavior.
7. A catalog configures decisions; it does not contain algorithms.
8. LLMs communicate but do not decide.
9. Human authorization controls publication and future execution.
10. Documentation and tests are release artifacts.
