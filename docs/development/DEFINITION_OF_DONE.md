# Definition of Done

Status: **Implemented**

A change is done only when:

- documented acceptance criteria are satisfied;
- relevant Domain/Application/Infrastructure/interface tests pass;
- tenant authorization and RLS implications are reviewed;
- migrations and Prisma stay synchronized when persistence changes;
- lint, format, typecheck, tests and build pass;
- public or architectural behavior is documented;
- implementation status is updated without overstating availability;
- GitHub Actions pass;
- no automatic merge occurs without authorization.
