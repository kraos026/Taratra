# Review Process

Status: **Implemented**

Reviews check, in order:

1. business scope and non-goals;
2. bounded-context ownership;
3. invariants and lifecycle;
4. dependency direction and transaction boundary;
5. multi-tenancy, RLS and authorization;
6. determinism, provenance and versioning;
7. tests and failure behavior;
8. documentation and operational impact.

Frozen contracts require a new Architecture Review before modification.
